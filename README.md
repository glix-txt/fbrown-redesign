# F Brown (Scotland) Ltd: website redesign

A redesign concept for [fbrownscotland.co.uk](https://www.fbrownscotland.co.uk/about). It is one static page: index.html, styles.css, script.js and favicon.svg.

The logo, CHAS and Constructionline images are loaded from the original site URLs. All contact details and company facts come from the current site.
